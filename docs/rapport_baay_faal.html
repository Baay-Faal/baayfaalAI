🚀 3. Mode d'Emploi Pas-à-Pas

1. Démarrage de l'Agent Web & Command Center

python web/server.py

L'interface graphique est immédiatement disponible sur http://localhost:8000.

2. Activation de la Sécurité Web par Clé d'API

# Windows PowerShell $env:BAAY_WEB_API_KEY="votre_cle_secrete_hyper_securisee" python web/server.py

3. Configuration d'un Nœud Distant (Network Nodes)

Sur la machine distante à piloter :

python network/node_daemon.py --port 9999 --secret votre_cle_partagee

4. Création d'un Plugin Personnalisé

Déposez un fichier dans plugins/mon_extension.py exposant un dictionnaire PLUGIN_MANIFEST, puis cliquez sur "Recharger Plugins" dans l'interface.

5. Exécution des Tests Unitaires de Validation

python -m unittest discover tests
