Guide Pratique d'Utilisation

COMMENT UTILISER L'AGENT IA BAAY-FAAL

Manuel complet d'installation, pilotage web, création de plugins et administration réseau

1. Prise en Main & Lancement Rapide

Étape A : Démarrer le Serveur Web Command Center

Ouvrez un terminal dans le dossier du projet et exécutez la commande suivante :

python web/server.py

L'agent démarre immédiatement le serveur HTTP natif et le planificateur Cron d'arrière-plan. Accédez à l'interface via votre navigateur à l'adresse : http://localhost:8000

Étape B : Lancer les Tests automatisés (Validation)

Pour vérifier que les 46 modules unitaires sont 100% opérationnels :

python -m unittest discover tests

3. Comment Ajouter un Plugin Personnalisé

Le système de plugins vous permet de donner à l'agent de **nouvelles compétences** sans jamais modifier le code source principal.

  1. Créez un nouveau fichier Python dans le dossier plugins/ (ex. plugins/mon_outil.py).
  2. Définissez la fonction Python et son dictionnaire obligatoire PLUGIN_MANIFEST :
# Fichier : plugins/mon_outil.py def calculer_surface(largeur: float, longueur: float) -> dict: return {"success": True, "surface": largeur * longueur} PLUGIN_MANIFEST = { "name": "calculer_surface", "description": "Calcule la surface d'une pièce en mètres carrés.", "parameters": { "type": "object", "properties": { "largeur": {"type": "number", "description": "Largeur en mètres"}, "longueur": {"type": "number", "description": "Longueur en mètres"} }, "required": ["largeur", "longueur"] }, "function": calculer_surface }

Cliquez sur "Recharger Plugins" dans l'interface ou dites à l'agent : "Recharge les plugins". L'outil est immédiatement actif !

4. Pilotage de Machines Distantes (Réseau de Nœuds)

L'agent Baay-Faal peut commander d'autres ordinateurs sur votre réseau local ou VPN de manière sécurisée via HMAC-SHA256.

Sur la machine distante à piloter :

Lancez le démon réseau natif avec un port et un secret partagé :

python network/node_daemon.py --port 9999 --secret ma_cle_secrete_hmac

Dans la configuration de l'Agent principal (config/nodes.json) :

Ajoutez le nœud distant avec son adresse IP et son secret :

[ { "node_id": "serveur_local_01", "host": "192.168.1.50", "port": 9999, "secret": "ma_cle_secrete_hmac" } ]

5. Sécurisation & Déploiement à Distance

  • Activer la Clé d'API Web : Définissez la variable d'environnement BAAY_WEB_API_KEY="votre_cle" avant de démarrer server.py. L'accès web sera immédiatement protégé par mot de passe.
  • Déploiement Distant Gratuit :** Utilisez Cloudflare Tunnel ou Tailscale pour accéder à votre agent depuis votre smartphone ou PC portable partout dans le monde en HTTPS sécurisé.
